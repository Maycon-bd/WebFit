# Prompt 00 — Iniciar o repositório

Copie e envie o texto abaixo no novo repositório.

---

Você está iniciando o WebFit Desktop como produto novo. Leia integralmente `AGENTS.md`, `docs/project/context.md`, `docs/project/legacy-migration.md`, `docs/project/development-lifecycle.md` e `docs/project/legacy-import-manifest.md` antes de agir.

Nesta etapa, não implemente funcionalidades nem copie código do WebFit Web.

Faça o seguinte:

1. inspecione o repositório e confirme que não há segredos ou artefatos indevidos;
2. crie a estrutura documental canônica definida em `development-lifecycle.md`;
3. crie um README inicial explicando objetivo, estado e como navegar na documentação;
4. crie `docs/project/decision-log.md` e `docs/project/risk-register.md` com templates úteis;
5. crie `docs/architecture/adr/ADR-0001-desktop-tauri-sqlite.md` como decisão proposta para validação por spike, sem tratá-la como comprovada;
6. crie a matriz de rastreabilidade vazia com instruções de preenchimento;
7. registre lacunas e decisões necessárias, sem inventar respostas;
8. valide links e formatação;
9. apresente os arquivos criados, decisões pendentes e o Gate G1.

Não instale dependências e não execute `create-tauri-app` nesta etapa.
